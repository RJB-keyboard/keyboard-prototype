# 五十音グライドキーボード

五十音表のタップ・グライドから候補を表示し、候補のタップで確定するAndroid IMEのプロトタイプです。Android 7.0（API 24）以降に対応します。

軌跡認識・GPT-2の次かな予測・辞書を組み合わせて読みを探索し、辞書ベースでかな漢字変換します。モデルと辞書は端末内で動作し、入力中の通信や入力内容・軌跡の永続保存は行いません。

## はじめる

1. [開発手順](docs/development.md#必要な環境)に従って環境を用意し、[モデルを取得](docs/development.md#ビルド準備)します。
2. Android Studioでプロジェクトを開き、実機またはエミュレーターで `app` をRunします。
3. アプリの「1. キーボードの設定を開く」から「五十音グライド（試作）」を有効にし、「2. キーボードを選ぶ」で選択します。
4. 試し入力欄で文字をタップするか、指を置いたまま複数の文字をなぞります。指を離し、表示された候補をタップすると確定します。

初回はモデルと辞書の読み込みに時間がかかります。英数字・記号を入力する際は、候補欄右上の「ABC」で他のキーボードへ切り替えられます。

## 現在の制約

学習による個人最適化は未実装です。認識・変換の係数は実操作データによる調整が必要です。文書内の合成軌跡・固定読みでの比較結果は、実際のユーザー入力の精度を保証するものではありません。条件と結果は [探索エンジンの検証](docs/engine.md#検証) と [変換候補の比較結果](docs/conversion.md#比較結果と再現) を参照してください。
