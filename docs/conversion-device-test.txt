かな漢字変換：実機テスト文章
対象：feature/conversion の候補順位付け・漢字表記の文脈評価の改善

目的
  同じ読みの第2・第3の漢字候補が、別の読みの候補に埋もれず選べるか確認する。
  スコアの近い別の読みも上位に残り、複数の解釈を選び分けられるか確認する。
  下の「目標表記」は入力したい文章の例。現在の辞書での収録・候補順位は未確認。
  同音異義語を文脈なしで必ず第1候補にすることを合格条件にはしない。

準備と操作
  1. メモアプリなど、内容を消して繰り返し試せる通常の入力欄を使う。
  2. 端末・画面の向き・入力アプリをそろえる。初回の読込後に「にほんご」を一度試す。
  3. 各試行の前に入力欄を空にし、カーソルの前に文章がない状態にする。
  4. 「なぞる読み」を1回のグライドで入力する。文字ごとのタップには分けない。
  5. 候補を確定する前に、表示順と目標表記の順位を記録する。
     横スクロールできる場合は右端まで確認する。順位は先頭を1と数える。
  6. 目標があればタップして、入力欄にその表記が確定することも確認する。
     次の試行では入力欄を再び空にする。削除は入力アプリや別のIMEの機能を使ってよい。

  ・記号・句読点の入力は今回の対象外。以下の文章にも句点を付けない。
  ・濁音・小書き文字は元のキーをなぞる（例：ご→こ、ゃ→や、ょ→よ、っ→つ）。
  ・まずAを各3回試す。B〜Eは各1回、気になる例を追加で2回試す。
  ・変更前APKがあれば同じ条件で比較する。手でなぞり直す比較には軌跡の差も含まれる。
    厳密な順位付けだけの比較には、同じ読み候補・コストを使う自動テストが必要。

============================================================
A. 最優先：同音異義語の選びやすさ
============================================================
目標表記の順位に加え、「見たい別候補」がどこに出るかも記録する。
別候補は存在・表示を保証するものではない。出なければ「候補外」と記録する。

A01
  目標表記：箸
  なぞる読み：はし
  見たい別候補：橋、端

A02
  目標表記：紙
  なぞる読み：かみ
  見たい別候補：髪、神

A03
  目標表記：飴
  なぞる読み：あめ
  見たい別候補：雨

A04
  目標表記：着る
  なぞる読み：きる
  見たい別候補：切る

A05
  目標表記：変える
  なぞる読み：かえる
  見たい別候補：帰る、替える

A06
  目標表記：会う
  なぞる読み：あう
  見たい別候補：合う、遭う

A07
  目標表記：胃が痛い
  なぞる読み：いがいたい（元のキー列：いかいたい）
  見たい別候補：いか買いたい、イカ買いたい、いかかいたい
  確認：胃が痛いが上位3件にあるか。買い物の候補がある場合、そちらも選べるか。
        買い物を意図してなぞった場合も試し、片方への決め打ちになっていないか記録する。
        濁音の誤認と「か」の重複は分けて記録する。両方の読みが必ず生成されるとは限らない。

============================================================
B. 基本動作：よく使う言葉
============================================================
B01
  目標表記：日本語
  なぞる読み：にほんご

B02
  目標表記：天気
  なぞる読み：てんき

B03
  目標表記：こんにちは
  なぞる読み：こんにちは

B04
  目標表記：ありがとう
  なぞる読み：ありがとう

確認：漢字だけでなく、かなのまま確定したい言葉も選べるか。
      最上位の読みそのものを残す仕様だが、意図した読みが最上位とは限らない。

============================================================
C. テスト文章：複数語を一度に変換
============================================================
C01
  目標表記：今日はいい天気です
  なぞる読み：きょうはいいてんきです

C02
  目標表記：日本語を勉強しています
  なぞる読み：にほんごをべんきょうしています

C03
  目標表記：紙に名前を書く
  なぞる読み：かみになまえをかく

C04
  目標表記：友達に会う
  なぞる読み：ともだちにあう

追加で比較したい読み（いずれも1回のグライド）：
  せんせいにあう → 先生に会う
  さいずにあう → サイズに合う
  きがあう → 気が合う
  ふくをきる → 服を着る
  きをきる → 木を切る
  しゃしんをとる → 写真を撮る
  かわでおよぐ → 川で泳ぐ
  はながいたい → 鼻が痛い（正しい読みを渡すテストでは3位→4位と悪化）
  いがいたい → 胃が痛い（文脈補正の修正後は7位→1位）
  あたまがいたい → 頭が痛い
  はがいたい → 歯が痛い

確認：目標表記の順位、変な語の区切り、途中の文字抜けを記録する。
      「良い／いい」などの表記違いがあれば、目標表記の順位とは別に許容候補として記録する。

============================================================
D. 読みの認識も難しい例
============================================================
D01
  目標表記：東京
  なぞる読み：とうきょう
  元のキー列：とうきよう

D02
  目標表記：学校
  なぞる読み：がっこう
  元のキー列：かつこう

D03
  目標表記：写真
  なぞる読み：しゃしん
  元のキー列：しやしん

確認：濁音や小書き文字の取り違えを、漢字候補の順位とは分けてメモする。
      「とうきょう」は既存の合成軌跡評価でも読みが上位8件に入らなかった例。
      今回の変更だけで読みの認識が改善するとは限らない。

============================================================
E. かなを残す例：架空の名前
============================================================
E01
  目標表記：ぬめらぽ
  なぞる読み：ぬめらぽ
  元のキー列：ぬめらほ

確認：かなの候補を選べるか。不自然な漢字しか出ない場合はその候補も記録する。
      架空名でも辞書内の短語に分解できることがあるため、未知語判定は保証しない。

結果の見方
============================================================
・A：見たい漢字候補が上位3件、または以前より上位に出るかを重点的に見る。
・B／C：以前選べた候補が消えていないか、基本語・文章の順位が悪化していないかを見る。
・D／E：文字の認識と候補順位の両方を記録する。
・1語あたりの漢字候補は最大3件、全体の表示は最大12件。
  漢字が候補外でも、原因は順位付け・読みの認識・辞書候補の生成のいずれもあり得る。
  画面だけでは読み候補の全件は分からないため、原因を断定せず記録する。
・実施した全試行に対して「目標が第1候補」「上位3件」「候補内」の件数を集計する。
  候補外・エラーも集計に含め、A〜Eごとに比較する。未実施は分母に含めない。
・実機の「10番目→3番目」を必須条件にはしない。その数字は固定データの自動テストの結果。
