# 操作ガイド

[READMEに戻る](../README.md)

## キーボードを有効にする

1. [開発手順](development.md#ビルド準備)に従ってモデルを取得し、Android Studioから実機またはエミュレーターで `app` をRunします。
2. アプリの「1. キーボードの設定を開く」から「五十音グライド（試作）」を有効にします。
3. アプリへ戻り、「2. キーボードを選ぶ」で「五十音グライド（試作）」を選択します。
4. 試し入力欄をタップし、五十音表の文字をタップするか、指を置いたまま複数の文字をなぞります。
5. 指を離すと軌跡と文脈から生成した変換候補が表の上に表示されます。候補をタップすると入力先へ確定します。

初回はモデルと辞書の読み込みに時間がかかります。以前の「あいキーボード」と同じアプリ・IMEコンポーネントなので上書き更新できます。

エミュレーターで表示されない場合は、物理キーボード接続時にもソフトウェアキーボードを表示する設定を有効にしてください。

## キーボード配置と補助キー

表は右から左に「あ・か・さ・た・な・は・ま・や・ら・わ」の10列で、各列は上から下に並びます。現代仮名46文字と「ー」の47キーを配置し、や行・わ行の空きマスはキーにしません。「っ」の独立キーはありません。

```text
わ ら や ま は な た さ か あ
を り    み ひ に ち し き い
ん る ゆ む ふ ぬ つ す く う
   れ    め へ ね て せ け え
ー ろ よ も ほ の と そ こ お
[ ← ] [ 、。 ] [ スペース ] [ 改行 ] [ → ]
```

- 上部は候補一覧を2行で表示し、右下に削除キーを配置します。
- 下段はカーソル左・句読点・全角スペース・Enter・カーソル右を幅1:1:2:2:1で配置します。通常の改行キーは「改行」と表示します。Enterは入力先に応じて改行・検索・送信などを実行します。
- 削除はUnicodeコードポイントまたは選択範囲を対象とします。押した直後に1回削除し、400ms長押しすると80ms間隔で削除し続けます。指を離す、キーの外へ移動する、キーボードを閉じると停止します。
- 地球儀などのOSボタン用に、最低48dpの専用領域と8dpの間隔を確保します。IME caption bar・navigation bar・切り欠きがそれ以上の領域を要求した場合は拡張します。
- 独自の収納キーは設けず、OS側の収納操作を利用します。
- 試し入力欄はキーボード表示に合わせてスクロールし、入力中のカーソル行を見える位置に保ちます。文字列内のカーソル位置は変えません。
- 左右キーは入力先へ方向キーイベントを送り、カーソルを移動します。
- 削除・句読点・スペース・Enter・左右キーでは未確定候補を消し、実行中の候補生成結果を無効化します。

## タップとグライド

グライド中は線と現在のキーを強調表示します。

- 新しい軌跡を開始すると前の候補を消します。候補確定後、IMEを閉じたとき、入力先の切り替え時にも状態をリセットします。
- 空きマスから始めた操作は無視します。
- 表の外で指を離す、操作がキャンセルされる、2本目の指を置く場合は、その軌跡を破棄します。
- 横画面は表の高さを縮め、入力先を表示したままにします。
- 濁音・半濁音・小書き文字は元のキーの確率的な別候補です（例：は→は／ば／ぱ、や→や／ゃ）。連続する同じ文字は1回の通過から最大3文字まで補完候補に含めます（例：こ→ま→よ から「ごままよ」）。同じキーで小さな往復をする操作も使えます。

## 候補の表示と選択

候補欄は22spの文字を2行で表示します。各行は候補の文字幅に合わせて独立して詰め、左右の内側余白は6dp、タップ領域は最低48dpを確保します。長い候補は折り返さず、横スクロールで全文を確認できます。

背景は、候補の相対的な確からしさが低いほど薄い青、高いほど薄い緑になります。通常表示・展開一覧で同じ色を使います。色はエンジンのスコアから求めた目安で、実測の正解率ではありません。確からしさが取得できない候補は白背景です。

### 候補一覧の展開

候補が表示されたら右上の「⌄」で一覧を五十音キーの領域まで広げられます。展開中は縦にスクロールして候補を選べます。「⌃」で候補を保持したまま五十音キーに戻ります。候補確定・削除・スペース・改行・カーソル移動・入力先の切り替えでは通常表示に戻ります。キーボード全体の高さとOSボタン用の余白は変わりません。展開しても候補の生成件数は変わりません。

## 句読点のフリック入力

句読点キー「、。」は、指を離すと選択した記号を直接入力します。斜めは移動量の大きい軸で判定します。

| 操作 | 入力する文字 |
| --- | --- |
| タップ | 、 |
| 左フリック | 。 |
| 上フリック | ！ |
| 右フリック | ？ |
| 下フリック | ...（半角ピリオド3つ） |

句読点キーを押している間は、キーの上に十字型のフリック案内を表示します。中央は「、」、上下左右は表の対応どおりです。選択中の記号はキー上にも表示し、案内では青背景・白文字で強調します。指を離す・キャンセル・キーボードを閉じると案内を消します。

## 英数字・記号を他のキーボードで入力する

- 候補欄右上の「ABC」をタップすると、直前に使ったキーボードへ切り替えます。戻れない場合は次のキーボードを試し、切り替え先がなければ選択一覧を開きます。
- 「ABC」を長押しすると、Androidのキーボード選択一覧を開きます。Gboardなど、英数字・記号を入力できるキーボードを事前に端末の設定で有効にしてください。
- 外部キーボードに切り替えた後、必要に応じてそのキーボードの英字／数字／記号キーを押してください。他のIMEの内部配列をこのアプリから指定することはできません。日本語入力へ戻るには、外部キーボードまたはOSの切り替え操作から「五十音グライド（試作）」を選択します。
- 切り替え時は未確定候補・軌跡を消し、処理中の候補生成を無効化します。候補を入力したい場合は切り替える前に確定してください。

## 入力データと制約

入力中の通信や、入力内容・軌跡の永続保存は行いません。学習による個人最適化は未実装です。文脈を参照する範囲や保存しないデータの詳細は [文脈とデータの扱い](architecture.md#文脈とデータの扱い) を参照してください。

候補品質は実操作データによる調整が必要です。[探索エンジンの検証](engine.md#検証)に記載した合成軌跡での結果は、自由な入力の認識率を保証するものではありません。
